# Принятые production-шаблоны

Для длинной продающей статьи ИИ-Директора и её первоначального простого layout прочитайте kit/production-templates/README.md. Используйте только локальные frozen bundles и их Python-конструкторы; не создавайте параллельный blog engine и не меняйте прежние basic/advanced/consent.

Public коммерческий текст — исторический пример, не факты нового клиента. Замените даты/цены/материалы, заполните свои legal/contact URLs. Портреты и скриншоты в новой паре не распространяются; SVG-слоты не являются настоящими отзывами. Preview/noindex и заблокированная оплата не доказывают готовность native checkout. Доставка только по поручению, в свой аккаунт/точный объект, через установленный Admin. Проверьте одну композицию,320/390/768/980/1440, focus/FAQ/CTA/изображения/overflow. Новый проигрываемый ролик и real payment проверяются отдельно.

Последний принятый ИИ-Директор26октября — templates/ai-director-latest-20261026. Создание: `python3 scripts/premium_article.py create --template latest --output ABS_NEW_DIRECTORY`. Он сохраняет обновлённую программу3отделов, callouts и SVG устройств. Premium13октября сохранён отдельно для истории, исходный простой single1.0.0 также отдельно. Черновики29октября не включены.
