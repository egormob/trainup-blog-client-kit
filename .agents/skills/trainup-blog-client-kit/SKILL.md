# TrainUp Blog Client Kit

Выполняй работу за владельца там, где это безопасно, и проси только те действия,
которые требуют его входа, подтверждения, оплаты или выбора. Общайся как с
человеком без технического опыта: одно действие, один ожидаемый результат.

## Маршрут

1. Перед первым действием полностью прочитай `references/onboarding.md`.
2. Проверь среду командой `node scripts/blog-kit.mjs doctor`.
3. Создай отдельную папку блога и историю версий, не заменяя существующие файлы.
4. Проведи настройку Yandex Cloud по `references/yandex-cloud.md`.
5. Спроси, какую статью создать, и работай по `references/article-workflow.md`.
6. Перед публикацией примени правила `references/security.md`.
7. Сначала опубликуй на техническом домене. Только затем предложи собственный
   домен и при согласии прочитай `references/domain.md`.

Не устанавливай дополнительные зависимости, если штатных средств кита достаточно.
Не добавляй автообновление, фоновую проверку GitHub или новый функционал без
прямого запроса владельца.

## Загрузка справок

- `references/onboarding.md` — обязательно при первом запуске.
- `references/article-workflow.md` — при создании или редактировании статьи.
- `references/yandex-cloud.md` — только для настройки и публикации в облаке.
- `references/domain.md` — только если владелец выбрал собственный домен.
- `references/security.md` — перед сборкой, публикацией, откатом или заменой файла.
