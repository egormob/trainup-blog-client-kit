# Пользовательские материалы

Эта папка принадлежит владельцу блога. Здесь хранятся его настройки, статьи и
публичные ассеты. Код кита находится отдельно в `kit/` и `scripts/`.

Codex не должен молча заменять существующие файлы в этой папке. Перед явной
заменой он показывает изменения, а исходную версию сохраняет в игнорируемой
папке `.blog-state/backups/`.
