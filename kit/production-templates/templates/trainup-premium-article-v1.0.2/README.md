# ИИ-директор — публичный пример принятого лендинга

Основа: trainup-premium-article1.0.2, commit3e84b7ffa2a8d83d0ea68cca77c44a2892db462a. Коммерческий текст — исторический публичный пример, не действующее предложение клиента. Фотографии/отзывы заменены подписанными геометрическими местами для собственных разрешённых материалов.

Из корня engine: `python3 scripts/premium_article.py check-template`, затем `python3 scripts/premium_article.py create --output ABS_NEW_DIRECTORY`. Результат index.html и raw-html.html; preview блокирует оплату. Редактируйте components/settings экземпляра, затем build. Реальную оплату и видео подключайте только для своего аккаунта и отдельно проверяйте.

CSS/runtime и единая адаптивная композиция сохранены. Исторический кабинетный HTML и его IDs не распространяются. Файл reference не нужен: manifest проверяет публичную производную, source hash сохраняет происхождение.
